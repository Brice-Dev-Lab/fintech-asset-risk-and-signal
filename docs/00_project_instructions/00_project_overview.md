# 📊 Multi-Asset Risk & Signal Dashboard

## 🧠 Overview

This project builds a foundational data pipeline for analyzing multi-asset financial data using Pandas.

The goal is to transform raw market data into structured datasets and extract basic risk signals.

---

## 🎯 Objective

Answer the following:

- Which assets are most volatile over time?
- When does risk increase across markets?
- How do returns behave during high volatility?
- How do different asset classes compare?

---

## 📦 Assets Used

- SPY (Market)
- QQQ (Tech)
- TLT (Bonds)
- GLD (Gold)
- ^VIX (Volatility)

---

## 🧭 Pipeline

    API → Clean → Features → Reshape → Merge → Analyze

---

## 💡 Key Skills

- Time series handling
- Feature engineering
- Data reshaping
- Merging datasets
- Risk analysis fundamentals
